Frequently Asked Questions

Gyan Shikshaનો ઉપયોગ, Quiz Saathi અને content વિશે સામાન્ય પ્રશ્નોના જવાબ.

શું Gyan Shiksha official government website છે?

ના. Gyan Shiksha independent educational website છે. Official board notice, timetable અથવા government rule માટે original authorityનો source final ગણવો.

Website કોના માટે છે?

હાલ મુખ્ય focus Gujarati Medium Std. 6–12 છે, જેમાં Std. 10 અને Std. 12 Board Exam preparationને ખાસ priority છે.

શું Quiz Saathi free છે?

હાલ websiteમાં જોડાયેલ Quiz Saathi practice માટે free રીતે ઉપલબ્ધ છે.

Quizમાં School Name અને Student Name શા માટે લેવાય છે?

Current quiz flowમાં attempt/score record અને educational reporting માટે આ fields ઉપયોગમાં આવે છે. વધુ વિગતો Privacy Policyમાં આપવામાં આવી છે.

Quiz score official result છે?

ના. Quiz score માત્ર practice feedback છે; school અથવા boardનું official result નથી.

Study Material ક્યાંથી આવશે?

Original notes, practice resources અને properly sourced/allowed material ઉમેરાતાં Study Material libraryમાં publish કરવામાં આવશે.

Board update સાચી છે કે નહીં તે કેવી રીતે ખબર પડશે?

Current update publish કરતાં official source verify કરવાનો editorial rule છે. Updates page પર source વગર demo/current headline publish નહીં કરવામાં આવે.

Educational Gamesમાં personal data લેવાય છે?

Current browser games login અથવા personal details લેતા નથી. Best score માત્ર તે browser/deviceના local storageમાં રહે છે.

Contentમાં ભૂલ જણાય તો શું કરવું?

Contact page પરથી page URL અને correction details મોકલો. Verified correction પછી content update કરી શકાય છે.

શું website પર advertisements આવશે?

ભવિષ્યમાં Google AdSense માટે application કરવાનો હેતુ છે. Approval પહેલાં real ads સક્રિય નથી અને adsને navigation/quiz controlsથી અલગ રાખવામાં આવશે.
