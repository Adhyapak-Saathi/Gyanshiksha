Self-Test

Self-Test શા માટે જરૂરી છે?

Test માત્ર marks મેળવવા માટે નથી. Self-test તમને શું આવડે છે, શું અડધું આવડે છે અને શું ફરી શીખવું છે તે બતાવતું learning tool છે.

Gyan Shiksha EditorialEvergreen GuideStd. 6–12

Reading confidence અને actual recall અલગ છે

Book ખુલ્લી હોય ત્યારે answer ઓળખાય એટલે ઘણીવાર “મને આવડે છે” એવું લાગે છે. પરંતુ examમાં clue વગર answer યાદ કરવો પડે છે. Self-test આ difference તરત બતાવે છે.

Wrong answer સૌથી useful signal છે

ખોટો જવાબ failure નથી; તે next revision ક્યાં કરવી તેનો signal છે. દરેક wrong answerને ચાર categoriesમાં મૂકી શકો: concept, memory, question-reading અથવા calculation/presentation.

Quiz પછી શું કરવું?

  1. Score જુઓ, પરંતુ ત્યાં અટકશો નહીં.
  2. ખોટા પ્રશ્નોની explanation વાંચો.
  3. Related concept textbook/notesમાં પાછું જુઓ.
  4. થોડા સમય પછી એ જ પ્રકારનો પ્રશ્ન ફરી solve કરો.
Best use of a quiz:

Test → Feedback → Revision → Retest. માત્ર Test → Score નહીં.

કેટલા પ્રશ્નો પૂરતા?

Daily quick check માટે 5–10 સારી quality questions પૂરતા હોઈ શકે છે. Chapter revision માટે 15–25 questions અને exam preparation માટે mixed/timed practice ઉપયોગી બની શકે છે. Quantity કરતાં coverage અને feedback મહત્વપૂર્ણ છે.

Exam પહેલાં self-test

Final weekમાં full-length test દરરોજ કરવો જરૂરી નથી. તેના બદલે weak topics, error log, formulas અને previous mistakesમાંથી targeted mini-tests બનાવો.

Self-testingનો અર્થ પોતાને prove કરવો નહીં; પોતાને improve કરવો છે.
