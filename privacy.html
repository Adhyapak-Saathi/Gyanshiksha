Quiz Saathiમાં લેવામાં આવતી માહિતી

Quiz શરૂ કરતી વખતે વિદ્યાર્થી પોતે દાખલ કરે તે School Name અને Student Name, તેમજ પસંદ કરેલ Standard, Section/Class, Subject, Chapter, Difficulty, question count અને quiz attempt/score જેવી માહિતી Google Apps Script દ્વારા process થઈ શકે છે અને Google Sheetsમાં record થઈ શકે છે.

આ માહિતી શા માટે?

Quiz ચલાવવા, વિદ્યાર્થીનો attempt/score record રાખવા, question-bank usage સમજવા અને educational performance reports માટે આ માહિતીનો ઉપયોગ થઈ શકે છે.

શું લેવામાં આવતું નથી?

હાલના Quiz Saathi flowમાં password, payment card information અથવા home address માંગવાનો હેતુ નથી. આવી sensitive information કોઈ quiz fieldમાં દાખલ ન કરવી.

Google Services

Quiz backend Google Apps Script અને Google Sheets પર ચાલે છે. તેથી quiz ઉપયોગ કરતી વખતે Google infrastructure દ્વારા technical request data process થઈ શકે છે.
